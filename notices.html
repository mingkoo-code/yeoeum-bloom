사이트 안내와 라이선스

이 사이트에 관하여

여음 블룸의 소개와 배포파일 안내를 위한 정적 웹사이트입니다. 회원가입, 문의 폼, 광고, 방문 분석 스크립트, 외부 웹폰트를 사용하지 않습니다. 사이트 운영자가 설정하는 쿠키도 없습니다.

웹사이트는 GitHub Pages, 배포파일은 GitHub Releases를 이용해 제공합니다. 접속과 다운로드 과정에서 GitHub가 IP 주소 등의 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해주세요.

연락과 외부 링크

이메일 링크는 기본 메일 앱을 열며, 자동으로 메일을 보내거나 첨부파일을 전송하지 않습니다. 이메일로 직접 보내주신 주소·본문·첨부자료는 문의 대응을 위해 메일 서비스에서 처리됩니다. 문의 자료의 삭제 요청은 yeoeum@anotier.art로 보내주세요.

인스타그램과 모바일 앱 소개 링크는 각 외부 사이트로 연결됩니다. 공간 팩 제작 의뢰의 접수 조건과 개인정보 안내는 별도로 준비할 예정입니다. 이 홈페이지에는 측정 자료를 접수하는 기능이 없습니다.

플러그인의 데이터

블룸은 DAW에서 실행되는 오디오 효과 플러그인입니다. 설치파일에는 기본 세 공간을 포함하며, 개인 집 화장실 공간 팩은 포함하지 않습니다. 추가한 공간 팩은 사용자 컴퓨터에 보관하며, 오디오나 측정 자료를 제작자에게 자동 업로드하지 않습니다.

오픈소스 고지

플러그인에는 JUCE, VST3 SDK 및 형식별 관련 라이브러리를 사용합니다. 타사 저작권·라이선스 원문은 설치된 플러그인 번들의 Contents/Resources/Notices에 포함돼 있습니다. 원문을 아래에서도 확인할 수 있습니다.
